# Connect - Social Media App

A Full Stack Social Media Application built as part of the **CodeAlpha Full Stack Development Internship**. 

## 🚀 Features
- **User Authentication:** Secure Registration & Login using JWT and bcrypt.
- **Create Posts:** Users can create text posts and add images via URL.
- **Feed:** View posts from all users dynamically.
- **Like & Comment:** Interact with posts by liking and commenting.
- **User Profile:** View profile details and update profile pictures.
- **Seed Data:** Comes with an API route to auto-generate 50 demo posts.

## 💻 Tech Stack
- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB (Mongoose)
- **Authentication:** JWT (JSON Web Tokens)
